━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  STEP 1: Upload Menu to Firebase (5 minutes)
  ─────────────────────────────────────────
  
  npm install firebase-admin
  
  # Download serviceAccountKey.json from Firebase Console:
  # 1. Go to https://console.firebase.google.com
  # 2. Select project: urban-binge-oms
  # 3. Go to Project Settings > Service Accounts
  # 4. Click "Generate New Private Key"
  # 5. Save as "serviceAccountKey.json"
  
  node upload-menu.js
  
  ✅ Menu uploaded to Firestore!

  STEP 2: Push to GitHub (5 minutes)
  ──────────────────────────────────
  
  git add .
  git commit -m "Urban Binge website ready"
  git push origin main
  
  ✅ Code pushed to GitHub!

  STEP 3: Deploy to Vercel (10 minutes)
  ─────────────────────────────────────
  
  1. Go to https://vercel.com
  2. Click "Add New" > "Project"
  3. Select your urban-binge repository
  4. Add environment variables (from .env.local)
  5. Click "Deploy"
  
  ✅ Website is live!
